# 🛡 WPP Telegram Bot для Web-Panel-Proxy

Полноценный, удобный и красивый Telegram-бот на **Aiogram 3** для управления сервером **[web-panel-proxy](https://github.com/POLESNIESOVETI12/web-panel-proxy)** прямо из вашего мессенджера.

---

## 🚀 Возможности бота

* 🌐 **Мониторинг серверных подключений и Live-трафика (NEW 🔥)**:
  * Отображение всех серверных транспортов из раздела «Подключения»:
    * `VLESS XHTTP · напрямую` (TCP 443)
    * `Hysteria2 · основной` (UDP 8443)
    * `AmneziaWG 3.1` (UDP 52080)
    * `VLESS VK` (через CDN)
    * `VLESS Yandex` (через CDN)
  * **Определение активного маршрута в реальном времени**: значок **🔥 ТРАФИК ИДЕТ СЕЙЧАС** показывает, через какое именно подключение клиент сейчас скачивает данные (Hysteria, прямым VLESS или через CDN VK/Yandex).
  * Возможность включать и выключать любой транспорт (тумблер) прямо из Telegram!
* 📊 **Дашборд сервера в реальном времени**:
  * Нагрузка CPU, RAM, использование SSD/диска, аптайм сервера.
  * Статус служб: Xray Core, Caddy, MTProxy, Web Panel, OpenFlux.
  * Сводка по клиентам и общему входящему/исходящему трафику.
* 👥 **Управление клиентами (VLESS, Hysteria 2, MTProto, AmneziaWG)**:
  * Просмотр всех пользователей и подписок с постраничной навигацией и индикаторами статуса 🟢 / 🔴.
  * Включение и отключение клиента в 1 клик.
  * Мгновенная генерация и отправка **QR-кодов** для подключения.
  * Копирование готовых ссылок подключения (`vless://...`, `hysteria2://...`, `tg://proxy?...`).
  * Для AmneziaWG — автоматическая отправка `.conf` файла конфигурации в чат.
  * Переименование и безопасное удаление с подтверждением.
* 📦 **Управление мульти-подписками (Happ, Streisand, v2rayNG, sing-box)**:
  * Список активных подписок и потребленного трафика.
  * Просмотр подключенных устройств (HWID) и кнопка **отозвать устройство**.
  * Кнопка быстрого добавления в приложение Happ (`happ://add/...`).
  * Ротация (смена) ключа подписки в один клик.
* ➕ **Интерактивный мастер создания**:
  * Выбор типа (Мульти-подписка или отдельный протокол).
  * Задание имени и лимита устройств по HWID (0 = безлимит).
  * Мгновенная выдача QR-кода и ссылки сразу после создания.
* 💾 **Резервные копии**:
  * Кнопка «Скачать бэкап» — формирует официальный архив `.zip` с настройками, ключами и базой и отправляет документом в Telegram.
* 🔒 **Безопасность**:
  * Доступ строго по белому списку `ADMIN_IDS` (Telegram ID администратора). Неавторизованные пользователи не имеют доступа к боту.
  * `ADMIN_IDS` обязателен: если он пустой или некорректный, бот не запустится (а не откроется для всех).

## ⚡️ Быстрая установка на VPS (за 1 минуту)

Подключитесь к вашему VPS по SSH (где уже установлена `web-panel-proxy`) и выполните:

```bash
git clone https://github.com/MikeTheEngeneer/WPP-Telegram-Bot.git /opt/wpp-telegram-bot-src
cd /opt/wpp-telegram-bot-src
sudo bash install.sh
```

Скрипт установки:
1. Проверит системные зависимости (`python3-venv`, `qrencode`).
2. Запросит ваш **Bot Token** (полученный в [@BotFather](https://t.me/BotFather)) и **Telegram ID** (узнать можно в [@userinfobot](https://t.me/userinfobot)).
3. Создаст виртуальное окружение и установит библиотеки.
4. Настроит и запустит systemd-сервис `wpp-telegram-bot.service` с автозапуском при перезагрузке.

## 🛠 Управление службой бота на VPS

* Статус службы:
  ```bash
  systemctl status wpp-telegram-bot
  ```
* Просмотр логов:
  ```bash
  journalctl -u wpp-telegram-bot -f
  ```
* Перезапуск бота:
  ```bash
  systemctl restart wpp-telegram-bot
  ```
* Остановка:
  ```bash
  systemctl stop wpp-telegram-bot
  ```

## 🔄 Автообновление (опционально)

`autoupdate.sh` обновляет git-копию, из которой вы ставили бота (`/opt/wpp-telegram-bot-src`), и при новом коммите заново запускает `install.sh`. Включить проверку каждые 15 минут:

```bash
echo '*/15 * * * * root /opt/wpp-telegram-bot-src/autoupdate.sh' | sudo tee /etc/cron.d/wpp-telegram-bot
```

Лог: `/var/log/wpp-bot-autoupdate.log`. Учтите: автообновление запускает новый код из репозитория от root без вашей проверки.
